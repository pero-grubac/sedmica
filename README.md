## 🚀 Getting Started

> Service Workers require a local HTTP server — they don't run on `file://`.
**VS Code Live Server:**
```
Right-click index.html → Open with Live Server
```
Open `http://localhost:5500`

**Python:**
```bash
python3 -m http.server 8080
```
Open `http://localhost:8080`
